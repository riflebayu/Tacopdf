## Mengapa Server Pihak Ketiga Menjadi Sasaran Empuk Hacker?

Setiap kali dokumen dikirimkan melalui jaringan internet terbuka menuju server pengolah dokumen publik, ada beberapa titik kerentanan fatal yang siap dimanfaatkan oleh pihak tidak bertanggung jawab:

1. **Serangan Man-in-the-Middle (MitM):** Jika situs web pengolah PDF tidak menggunakan enkripsi end-to-end yang ketat, peretas dapat menyadap lalu lintas data saat proses pengunggahan berlangsung.
2. **Penyimpanan Sementara yang Permanen:** Banyak platform mengklaim bahwa file akan dihapus otomatis dalam waktu satu jam. Padahal, sistem pencadangan (*backup*) server sering kali menyimpan salinan bayangan (*shadow copies*) yang bertahan hingga berbulan-bulan.
3. **Data Scraping Otomatis:** Peretas kerap membuat bot khusus untuk memindai folder penyimpanan publik milik platform konverter gratisan yang sistem keamanannya lemah. Bot ini secara otomatis menyedot file PDF dan mengekstraksi data berharga seperti nomor kartu kredit, alamat rumah, hingga tanda tangan digital.

### Jejak Digital yang Tak Pernah Benar-benar Hilang

Saat Anda mengunggah dokumen berformat PDF, file tersebut mengandung *metadata*. Metadata mencakup informasi rinci mengenai perangkat yang digunakan, nama pemilik lisensi perangkat lunak, lokasi pembuatan file, hingga riwayat penyuntingan. Ketika file ini berada di server publik, peretas dapat membedah metadata tersebut untuk melancarkan serangan *phishing* yang sangat terspesialisasi (*spear phishing*).
