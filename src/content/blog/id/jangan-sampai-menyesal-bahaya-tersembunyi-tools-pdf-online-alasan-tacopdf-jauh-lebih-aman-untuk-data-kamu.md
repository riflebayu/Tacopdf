### Rekaman Metadata yang Lupa Dihapus

Setiap file PDF menyimpan metadata. Isinya bisa berupa nama perangkat, lokasi pembuatan file, hingga nama pemilik dokumen.

Tools yang asal-asalan sering kali membiarkan metadata ini tersimpan di server mereka.

Jika server mereka berhasil diretas, semua informasi sensitif kamu bakal langsung berpindah tangan.

Kebanyakan situs pemroses PDF populer berbasis di negara dengan aturan privasi yang samar.
